# Campaign Concept Studio

A responsive workspace for turning a real campaign brief into a clear creative direction.

## Scope of this foundation
- Next.js App Router and TypeScript.
- Responsive brief form and client-side concept outline.
- No fabricated campaign metrics, audience statistics, testimonials, integrations, or performance claims.
- No account system, database, analytics, AI provider, or external API is implied by this starter.

## Requirements
Node.js 20.9 or later and npm.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Verify
```bash
npm run typecheck
npm run lint
npm run build
```

## Privacy
The initial form processes input in the browser and does not persist it to a server. Avoid entering confidential data until a storage and privacy design is implemented.

## Vercel
Import this repository. Since the app files are at repository root, leave Root Directory blank. Test a Preview deployment first; production deployment requires a separate decision.

## Status
Starter scaffold only. Build, lint, typecheck, and deployment must be run and reviewed before calling this production-ready.
